## Linux Configuration

Personal Linux configuration files, scripts, and tooling for customizing my environment.

---

## Contents

* **`setup.sh`**
  Main installation script. Installs required packages and deploys configuration files.

* **`FastFetch_Fedora`**
  Configuration for Fastfetch system info display.

* **`gnome`**
  Scripts and tweaks for GNOME.

* **`mpv`**
  Custom configuration for mpv.

* **`powermanagement`**
  Power optimization scripts using TLP.

* **`reboot2menu`**
  Utility to reboot directly into BIOS/UEFI.

* **`starship-config`**
  Prompt configuration for Starship.

* **`vscode`**
  Editor configuration and extensions for Visual Studio Code.

* **`ytdown`**
  C++ CLI tool for downloading videos using yt-dlp.

* **`zsh-config`**
  Shell configuration for Zsh.

---

## Setup

```bash
git clone https://github.com/<username>/<repo>
cd <repo>
./setup.sh
```
